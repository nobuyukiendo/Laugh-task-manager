# Time Tracker Application

Googleカレンダーと連携可能な、詳細な作業時間記録アプリケーションです。
部門や作業種別ごとの時間記録、ダークモード対応、グラフによる可視化機能を備えています。

## 機能
- **詳細な時間記録**: 部門、作業種別、詳細タスクを指定して時間を記録。
- **Googleカレンダー同期**: 記録した作業ログを一括または個別にGoogleカレンダーへ転記（実績として保存）。
- **重複チェック**: カレンダー同期時に、予定の重複を検知し警告を表示。
- **可視化**: 日次、月次の作業内訳を円グラフやタイムラインで確認。
- **ダークモード**: システム設定または手動切り替え可能なダークテーマ。

## 動作環境・配布方法

このアプリケーションはWebアプリケーションです。以下のいずれかの方法で配布・利用できます。

### 1. ビルド済みファイル（distフォルダ）の配布
ビルドによって生成された `dist` フォルダの中身を、Webサーバー（Vercel, Netlify, Github Pages, または社内サーバー）にアップロードするだけで動作します。

**注意点**:
- Google Calendar APIを使用するため、Google Cloud Consoleでの設定（**承認済みのJavaScriptオリジン**）に、デプロイ先のドメインを追加する必要があります。
- `.env` ファイルはビルド時に埋め込まれます。Client IDを変更したい場合は、`.env` ファイルを書き換えて、再度ビルドする必要があります。

### 2. ソースコードとしての配布
開発者が見る場合や、修正を加える場合は、ソースコード全体を配布します。

#### セットアップ手順
1. Node.js (v18以上推奨) をインストールします。
2. フォルダ内でコマンドラインを開き、依存関係をインストールします。
   ```bash
   npm install
   ```
3. `.env` ファイルを確認します（Google Client IDが必要です）。
   ```
   VITE_GOOGLE_CLIENT_ID=あなたのGoogleClientID
   ```
4. 開発サーバーを起動します。
   ```bash
   npm run dev
   ```

## Google Calendar連携の設定 (管理者向け)

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスします。
2. 新しいプロジェクトを作成します。
3. **APIとサービス > ライブラリ** から「Google Calendar API」を有効にします。
4. **OAuth同意画面** を設定します（User Typeは「外部」または組織内のみなら「内部」）。
5. **認証情報 > 認証情報を作成 > OAuthクライアントID** を選択します。
   - アプリケーションの種類: **ウェブ アプリケーション**
   - 承認済みのJavaScriptオリジン:
     - ローカル開発用: `http://localhost:5173`
     - 本番用: `https://your-domain.com` (実際にデプロイするURL)
6. 生成された「クライアントID」をコピーし、`.env` ファイルの `VITE_GOOGLE_CLIENT_ID` に貼り付けてください。

## ビルド方法

配布用のファイルを生成するには以下のコマンドを実行します。
```bash
npm run build
```
`dist` フォルダが生成されます。

## ライセンス / 注意事項
このアプリケーションはブラウザの IndexedDB にデータを保存します。ブラウザのキャッシュをクリアするとデータが消える可能性があるためご注意ください。
